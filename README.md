# What's the surprise? 🎁

A small prank page built with Next.js.

- Big "What's the surprise?" message on the home screen
- "No, I won't tell" runs away whenever you hover, tap, or tab to it
- "Tell the surprise" opens a text box, then reveals the surprise with confetti
- Leaving is blocked until the surprise is told (close/refresh shows "Leave site?", Back and Escape show a "Not so fast!" popup)

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub and import into Vercel — no settings needed.
